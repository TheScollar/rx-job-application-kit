# Positioning

Your reusable career positioning assets. `/setup` creates all three files;
edit them by hand whenever your situation changes. `/apply` reads them on
every run.

| File | Purpose | Used in |
|---|---|---|
| `Target-Roles.md` | What you want: titles, domains, location, salary band, dealbreakers, must-haves | `/apply` pre-screen (Gate 1) |
| `Master-CV.md` | Source-of-truth CV in markdown, every role and metric | `/apply` fit analysis + tailored CV base |
| `Accomplishments.md` | Reusable STAR-style bullets tagged by theme | `/apply` bullet selection per JD |

Blank templates live in
`.claude/skills/rx-job-application-kit/references/positioning-templates.md`.
A filled example is in `examples/alex-sample/Positioning/`.
